# 🗣️ Lost in Darija

🔗 **[Try it live on HuggingFace Spaces](https://huggingface.co/spaces/ILyass-42/lost-in-darija)**

A speech-to-speech translation pipeline that converts spoken English into Moroccan Darija, designed for tourists navigating Morocco.

📝 **Write-ups**

- **[Part 1](./writeup.md)**: how the pipeline was built and deployed with Docker on HuggingFace Spaces, and its first evaluation on an independent benchmark (TerjamaBench). Its BLEU numbers are superseded by Part 2.
- **[Part 2](./writeup2.md)**: the rebuilt evaluation (sentence-grouped splits, chrF++ with bootstrap confidence intervals) and a study of synthetic data from DODa-500K. A paper is in preparation for AbjadNLP 2027.

---

## ✨ Features

- 🎙️ **Speech-to-Text**: transcribes English audio using OpenAI Whisper
- 🌍 **Neural Machine Translation**: translates English to Moroccan Darija using a fine-tuned MarianMT model (Helsinki-NLP/opus-mt-en-ar)
- 🔊 **Text-to-Speech**: synthesizes Darija audio using Microsoft Edge TTS (ar-MA-JamalNeural voice)
- 📊 **Evaluation**: chrF++ and BLEU with 95% bootstrap confidence intervals, on a sentence-grouped test split and on TerjamaBench

## 📚 Dataset

The translation model was fine-tuned on **[DODa: Darija Open Dataset](https://github.com/darija-open-dataset/dataset)**, the largest open-source English ↔ Darija parallel corpus. DODa covers both Arabic-script and Latin-script Darija.

**Part 1** used `sentences.csv` from DODa (48,818 rows, columns `darija`, `eng` and `darija_ar`, no missing value). The Latin-script `darija` column was dropped. A random row-by-row split gave 39,542 train, 4,394 validation and 4,882 test pairs (81/9/10). In May 2026, `data/Train.csv` and `data/Val.csv` were rebuilt: the old train and validation pairs were merged with the `comments` and `web_data` subsets of [`atlasia/darija_english`](https://huggingface.co/datasets/atlasia/darija_english) (2,955 new pairs after filtering and deduplication), then split again 90/10 (41,854 train, 4,651 validation). `data/Test.csv` was not changed.

**Part 2** uses the human rows of DODa-500K: 48,350 rows, 47,978 after removing identical pairs. Two synthetic sets of about 226,000 rows each (`doda_grounded` and `exploratory`) are tested as extra training data. The 70 English sentences of TerjamaBench are removed from all training data.

Two splits are built with the same seed:

- **Split A**: random, row by row.
- **Split B**: grouped by normalized English sentence, so train, validation and test share no English sentence (checked by script). All Part 2 results use split B.

> Outchakoucht, A. & Es-Samaali, H. (2024). *The Evolution of Darija Open Dataset: Introducing Version 2*. arXiv:2405.13016.

## 🧪 Fine-tuning

The base model [`Helsinki-NLP/opus-mt-en-ar`](https://huggingface.co/Helsinki-NLP/opus-mt-en-ar) was fine-tuned on DODa to adapt from Modern Standard Arabic (MSA) to Moroccan Darija. Source sentences were prepended with the `>>ary<<` language token (ISO 639-3 code for Moroccan Arabic) to direct the model's output toward Darija rather than MSA.

| Parameter | Value |
|-----------|-------|
| Base model | Helsinki-NLP/opus-mt-en-ar |
| Training pairs (split B, human data) | 38,097 |
| Epochs | 8 (best checkpoint: epoch 6, counted from 0) |
| Learning rate | 2e-5, cosine schedule with 6% warmup |
| Optimizer | AdamW |
| Batch size | 16 |
| Precision | Mixed precision |
| Seed | 42 |
| Hardware | Google Colab T4 GPU (A100 for the synthetic-data runs) |

The fine-tuned model of Part 1 is available on the HuggingFace Hub: **[ILyass-42/lost-in-darija-marian](https://huggingface.co/ILyass-42/lost-in-darija-marian)**. According to the git history, it was trained in April 2026 on the first random split of the DODa sentences, before the May merge with atlasia and before the grouped splits. The live Space loads this model (see the `Dockerfile`).
The models of Part 2 are not published yet.

## 🚀 Getting Started

### 1. Clone the repo

```bash
git clone https://github.com/Ilyass-42/lost-in-darija.git
cd lost-in-darija
```

### 2. Install dependencies

```bash
pip install pip-tools
pip-sync requirements.txt
```

> **Note:** `torch` must be installed separately depending on your hardware.  
> GPU (CUDA 12.1): `pip install torch --index-url https://download.pytorch.org/whl/cu121`  
> CPU only: `pip install torch`

> `requirements.txt` covers the app only. To train or evaluate, also run `pip install tensorboard datasets scikit-learn`: `fine_tune.py` imports `torch.utils.tensorboard`, `evaluate_mt.py` loads TerjamaBench with `datasets`, and `scripts/make_splits.py` uses scikit-learn.

### 3. Download or train the model

The fine-tuned model is not included in the repo (too large). You can either:

**Option A: Download from HuggingFace Hub** *(recommended)*:
```python
from transformers import MarianMTModel, MarianTokenizer
tokenizer = MarianTokenizer.from_pretrained("ILyass-42/lost-in-darija-marian")
model = MarianMTModel.from_pretrained("ILyass-42/lost-in-darija-marian")
# translate.py loads the model from this local folder (the Dockerfile does the same)
tokenizer.save_pretrained("models/fine_tuned_marian_v2")
model.save_pretrained("models/fine_tuned_marian_v2")
```

**Option B: Fine-tune yourself** (Part 2 setup):
```bash
python src/translation/fine_tune.py --split B --run_name small_B
# with synthetic data:
python src/translation/fine_tune.py --split B --run_name small_C1 --synthetic data/synthetic/doda_grounded.csv
```
Each run saves its best checkpoint (lowest validation loss) to `models/<run_name>_<date>` and logs to `runs/`. `--synthetic` works only with `--split B`. The synthetic CSV files are not in the repository. Create them first:
```bash
wget -O data/darija_parallel.jsonl https://media.githubusercontent.com/media/darija-open-dataset/dataset/main/doda-500k/darija_parallel.jsonl
python scripts/decontaminate_synthetic.py   # needs HF_TOKEN (see step 5)
```

**Option C: Use the base model** (no Darija adaptation):
Change `model_path` in `src/translation/translate.py` to `"Helsinki-NLP/opus-mt-en-ar"`.

### 4. Run the pipeline

```bash
python src/pipeline.py path/to/your/audio.mp3
```

The translated Darija audio will be saved to `data/results/`. Whisper needs `ffmpeg`, and Edge TTS needs internet access.

### 5. Evaluate a model

```bash
python src/translation/evaluate_mt.py --model <local folder or Hub ID> --dataset test --split B
python src/translation/evaluate_mt.py --model <local folder or Hub ID> --dataset terjama
```

TerjamaBench is a gated dataset: set `HF_TOKEN` (a token with read access to public gated repos) before `--dataset terjama`. `--split` is required with `--dataset test` and not allowed with `--dataset terjama`.

Decoding is the same for every model (`>>ary<<` prefix, `num_beams=4`, `length_penalty=1.2`). Results are saved to `results/`.

## 📊 Results (Part 2)

Scores come from `evaluate_mt.py`: BLEU (order 4) and chrF++, with 95% bootstrap confidence intervals (1,000 resamples). chrF++ is the main metric, because BLEU-4 is unstable on very short sentences.

| Model | Test B BLEU | Test B chrF++ | TerjamaBench BLEU | TerjamaBench chrF++ |
|---|---:|---:|---:|---:|
| Base model (`opus-mt-en-ar`, no fine-tuning) | 0.25 ± 0.11 | 11.04 ± 0.37 | 0.31 ± 0.18 | 16.24 ± 1.49 |
| Fine-tuned on human DODa data | 13.08 ± 0.90 | 35.60 ± 0.69 | 5.39 ± 1.38 | 34.44 ± 1.28 |
| + synthetic set `doda_grounded` | 11.90 ± 0.80 | 35.26 ± 0.65 | 10.70 ± 1.71 | 40.57 ± 1.57 |
| + synthetic set `exploratory` | 12.14 ± 0.81 | 35.47 ± 0.69 | 10.10 ± 1.78 | 41.13 ± 1.56 |

- In a manual check of 10 random examples, 9 of the base model's translations were in Modern Standard Arabic, not Darija.
- On TerjamaBench, a separate benchmark of 850 sentences in 12 categories, the synthetic data raises chrF++ by about 6 points. The intervals of the fine-tuned model and of the two synthetic runs do not overlap.
- On Test B, which comes from the same source as the training data, chrF++ does not change.
- The lowest chrF++ categories for the fine-tuned model are `dialect_variation` (15.58) and `idioms` (21.21). The synthetic data improves 11 of the 12 categories for `doda_grounded` and all 12 for `exploratory`. The per-category tables are in [`writeup2.md`](./writeup2.md).

**Status:** these results are preliminary. They come from one run per condition. The fine-tuned model ran on a T4 and the two synthetic runs on an A100. One synthetic run was stopped after 7 of 8 epochs. The differences are not tested with a paired bootstrap, and a paraphrase of a TerjamaBench sentence could remain in the synthetic data.

## ⚠️ Known Limitations

- TTS output has a slight MSA (Modern Standard Arabic) accent rather than a pure Darija accent.
- Darija is a low-resource language with limited parallel data.
- The Part 1 BLEU scores (18.30 and 10.23) used `max_ngram_order=3`, a test split that shared English sentences with the training data, and different decoding settings. They are superseded by the Part 2 results.
